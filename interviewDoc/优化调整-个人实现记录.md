# 任务1

手动指定运行窗口 X 和订单总数 Y，并按照选定的 arrival 模型，把这 Y 个订单安排在 X 秒内到达。

10骑手，20订单，2秒

```sh
go run ./cmd/matcher --strategy=balanced --algorithm=kd-tree --riders=10 --orders=20 --arrival-window=2s --arrival-model=uniform-window --top-k=4 --max-extra-distance=300 --workers=2 --batch-size=1 --channel-capacity=16 --monitor-interval=100ms
```

30s，1万订单，100骑手

```
go run ./cmd/matcher --strategy=balanced --algorithm=kd-tree --riders=100 --orders=10000 --arrival-window=30s --arrival-model=uniform-window --top-k=8 --max-extra-distance=300 --workers=2 --batch-size=1 --channel-capacity=16 --monitor-interval=100ms
```

burst：

```
go run ./cmd/matcher --strategy=balanced --algorithm=kd-tree --riders=100 --orders=10000 --arrival-window=30s --arrival-model=front-loaded-burst --top-k=8 --max-extra-distance=300 --workers=2 --batch-size=1 --channel-capacity=16 --monitor-interval=100ms

```
